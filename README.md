# Alena Pavlenko — Creative Portfolio

Одностраничный сайт-портфолио на чистом HTML, CSS и JavaScript. Сборка и установка программ не нужны: чтобы посмотреть сайт, откройте `index.html` в браузере.

## Что где лежит

| Файл или папка | Что в нём |
|---|---|
| `index.html` | Вся разметка и тексты: первый экран, «Обо мне», «Что я умею», контакты |
| `data.js` | Список работ — фотографии и видео. Единственный файл, который правится при добавлении работы |
| `style.css` | Оформление. Цвета собраны в самом начале, в блоке «2. Переменные» |
| `script.js` | Поведение: меню, фильтры, полноэкранный просмотр, видео. Трогать не нужно |
| `assets/images/` | Фотографии по папкам: `hero`, `food`, `product`, `people`, `about`, `visual-projects` |
| `assets/videos/` | Видео и обложки к ним |
| `assets/resume/` | Место для резюме в PDF |
| `assets/fonts/` | Шрифты Cormorant Garamond и Manrope |

Править файлы можно в любом текстовом редакторе (на Mac — TextEdit в режиме «Обычный текст» или бесплатный Visual Studio Code).

## Как подготовить фотографию

Перед тем как класть файл на сайт:

- формат **JPG** (HEIC с айфона большинство браузеров не показывает);
- длинная сторона **до 2000 пикселей**, вес до 500 КБ — иначе сайт будет грузиться медленно;
- имя файла **латиницей, без пробелов**: `food-11.jpg`, а не `Фото 1.jpg`.

На Mac уменьшить и пересохранить фото можно в «Просмотре»: Инструменты → Настроить размер, затем Файл → Экспортировать → JPEG.

## 1. Как заменить фотографии

Сохраните новый файл **под тем же именем** в ту же папку — он заменит старый, больше ничего менять не нужно.

| Что | Файл |
|---|---|
| Большое фото первого экрана | `assets/images/hero/hero-main.jpg` |
| Маленькое фото первого экрана | `assets/images/hero/hero-detail.jpg` |
| Портрет в «Обо мне» | `assets/images/about/portrait.jpg` |
| Обложка для ссылки в мессенджерах | `assets/images/og-cover.jpg` (1200×630) |
| Работы в галерее | `assets/images/food/`, `product/`, `people/` |

## 2. Как добавить новую работу

1. Положите фото в нужную папку, например `assets/images/food/food-11.jpg`.
2. Откройте `data.js` и добавьте в список `works` строку:

```js
    { category: 'food', type: 'photo', src: 'assets/images/food/food-11.jpg', ratio: '2:3',
      alt: 'Коротко: что на фотографии' },
```

- `category` — `'food'`, `'product'` или `'people'`: от этого зависит, под каким фильтром появится фото.
- `alt` — описание для тех, кто не видит картинку, и для поисковиков.
- `ratio` — примерные пропорции (`'2:3'`, `'3:4'`, `'3:2'`, `'1:1'`); нужны только пока фото грузится.
- Порядок строк в списке = порядок фото внутри своей категории.
- Необязательно: `title: 'Название'`, `year: 2026`, `description: 'Пара слов'` — появятся под фото в полноэкранном просмотре; `featured: true` — фото встанет на всю ширину сетки.

Каждая запись заканчивается запятой после `}`. Если после правки галерея пропала — скорее всего, потерялась запятая или кавычка.

**Убрать работу** — удалить её строку из `data.js`.

**Сколько фото видно сразу** — число `perPage` в начале `data.js` (сейчас 24); остальные открываются кнопкой «Показать ещё».

**Порядок категорий** — порядок строк в списке `categories` в `data.js`; первая открыта при загрузке сайта. Общий раздел «Все работы» выключен; чтобы вернуть его, поставьте `showAll: true`.

**Новая категория** — добавьте строку в список `categories` в `data.js`, например `{ id: 'travel', label: 'Путешествия' }`, и указывайте `category: 'travel'` у работ. Кнопка фильтра появится сама.

## 3. Как добавить видео

1. Подготовьте файл: формат **MP4 (H.264)**, имя латиницей. GitHub не принимает файлы больше 100 МБ, а через сайт GitHub загружаются файлы до 25 МБ — короткие ролики лучше сжимать до этого размера.
2. Положите видео в `assets/videos/`, рядом — картинку-обложку (любой кадр из ролика в JPG).
3. Добавьте запись в `data.js`:

```js
    {
      title: 'Название видео',
      type: 'video',
      src: 'assets/videos/my-video.mp4',
      poster: 'assets/videos/my-video-poster.jpg',
      ratio: '9:16',
      description: ''
    },
```

`ratio` — `'9:16'` для вертикального видео, `'16:9'` для горизонтального. Если обложки нет, строку `poster` удалите — будет показан первый кадр. Видео появляются в разделе «Видео» в том порядке, в каком идут в списке.

## 4. Как изменить текст

Все тексты — в `index.html`. Откройте файл, найдите нужную фразу поиском (Cmd + F) и исправьте её, не трогая то, что в угловых скобках `< >`.

- Разделы подписаны комментариями вида `<!-- ============ 03 · ОБО МНЕ ============ -->`.
- `&nbsp;` — неразрывный пробел: он не даёт короткому предлогу остаться в конце строки. Его можно оставлять или заменять обычным пробелом.
- Инструменты — строки `<li>CapCut</li>`: добавьте или удалите строку.
- Заголовок вкладки и описание для поисковиков — `<title>` и `<meta name="description">` в начале файла.

## 5. Как заменить контактные данные

В `index.html` найдите раздел `05 · КОНТАКТЫ`. Каждая строка выглядит так:

```html
<li>
  <span class="label">Почта</span>
  <a href="mailto:avezhlivtseva@mail.ru">avezhlivtseva@mail.ru</a>
</li>
```

Адрес меняется в двух местах: в `href="..."` (куда ведёт ссылка) и между `<a>` и `</a>` (что видно на сайте). Для почты в `href` пишется `mailto:адрес`, для Telegram — `https://t.me/ник`. Чтобы добавить ещё один контакт, скопируйте блок `<li>…</li>` целиком.

## 6. Как добавить PDF-резюме

1. Сохраните файл как `assets/resume/resume.pdf`.
2. В `index.html`, в списке контактов, добавьте перед строкой `</ul>`:

```html
<li>
  <span class="label">Резюме</span>
  <a href="assets/resume/resume.pdf" target="_blank" rel="noopener">Открыть PDF</a>
</li>
```

## 7. Как опубликовать сайт на GitHub Pages

### Первая публикация

1. Зарегистрируйтесь на [github.com](https://github.com). Имя пользователя попадёт в адрес сайта.
2. Нажмите **+** → **New repository**. Название — например `portfolio`, видимость — **Public**. Нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**. Откройте папку сайта, выделите **всё её содержимое** (Cmd + A) и перетащите в окно браузера. Перетаскивать нужно содержимое, а не саму папку — `index.html` должен лежать в корне репозитория.
4. Дождитесь загрузки и нажмите **Commit changes**. За один раз GitHub принимает до 100 файлов; если файлов больше, загрузите папки по очереди.
5. Откройте **Settings** → **Pages**. В блоке **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.
6. Через одну-две минуты сайт откроется по адресу `https://ИМЯ.github.io/portfolio/` — он же появится вверху страницы **Pages**.

### Красивая ссылка в мессенджерах

Чтобы при отправке ссылки показывалась обложка, в начале `index.html` укажите полный адрес картинки и добавьте адрес сайта:

```html
<meta property="og:url" content="https://ИМЯ.github.io/portfolio/">
<meta property="og:image" content="https://ИМЯ.github.io/portfolio/assets/images/og-cover.jpg">
```

### Обновление сайта

1. Откройте репозиторий и перейдите в папку, где лежит изменённый файл.
2. **Add file** → **Upload files**, перетащите новую версию (файл с тем же именем заменит старый) и нажмите **Commit changes**.
3. Сайт обновится сам через одну-две минуты. Если изменений не видно, обновите страницу без кэша: Cmd + Shift + R.

Когда правок станет много, удобнее поставить бесплатную программу [GitHub Desktop](https://desktop.github.com): она сама находит изменённые файлы и отправляет их одной кнопкой.

## Если что-то не работает

| Что видно | Причина и решение |
|---|---|
| Серый блок «Место для фото» с адресом файла | Файла нет по этому адресу. Проверьте имя, расширение и регистр букв: `Food-01.JPG` и `food-01.jpg` — разные файлы |
| Пропала вся галерея | Ошибка в `data.js` — обычно лишняя или потерянная запятая либо кавычка |
| На компьютере фото видно, на GitHub — нет | Чаще всего регистр букв в имени файла или файл не загружен в репозиторий |
| Изменения не появились на сайте | Подождите пару минут и обновите страницу через Cmd + Shift + R |
